Практическая работа «Регулярные выражения» (14 упражнений, 4 уровня) выполнена
в виртуальной машине VirtualBox под управлением Ubuntu 18.04 LTS.
Использованы GNU grep 3.1 (`-E` — ERE, `-P` — PCRE, `-o` — только совпадения)
и GNU sed 4.4.

## Состав репозитория

- `t01.txt … t14.txt` — тестовые данные к 14 заданиям (включая некорректные примеры);
- `figures/fig01.png … fig14.png` — скриншоты консольных сессий с проверкой выражений;
- `report/` — отчёт по практической работе (docx, pdf).

## Регулярные выражения по заданиям

| № | Задание | Регулярное выражение | Режим |
|---|---------|----------------------|-------|
| 1 | Точное слово cat | `\bcat\b` | grep -E |
| 2 | Одна цифра | `[0-9]` | grep -oE |
| 3 | Слово из трёх букв | `\b[a-z]{3}\b` | grep -oE |
| 4 | Все целые числа | `[0-9]+` | grep -oE |
| 5 | Слова с заглавной буквы | `\b[A-Z][a-z]*\b` | grep -oE |
| 6 | Email с зоной .com | `[[:alnum:]._%+-]+@[[:alnum:].-]+\.com` | grep -oE |
| 7 | Даты с проверкой диапазонов | `^(0[1-9]\|[12][0-9]\|3[01])\.(0[1-9]\|1[0-2])\.(19\|20)[0-9]{2}$` | grep -E |
| 8 | Удвоенные буквы в слове | `\b\w*([a-z])\1\w*\b` | grep -oP |
| 9 | Парные HTML-теги | `<([a-z]+)>.*?</\1>` | grep -oP |
| 10 | Пароль с жёсткими условиями | `^(?=.*[0-9])(?=.*[a-z])(?=.*[A-Z])(?=.*[!@#$%^&*]).{8,}$` | grep -P |
| 11 | URL с протоколом | `https?://[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}` | grep -oE |
| 12 | Числа с разделителями тысяч | `^([0-9]{1,3}(,[0-9]{3})+\|[0-9]+)$` | grep -P |
| 13 | Повторяющиеся слова | `\b(\w+)\s+\1\b` | grep -oiP |
| 14 | Текст в кавычках | `"[^"\\]*(?:\\.[^"\\]*)*"` | grep -oP + sed |

## Как воспроизвести проверку

```bash
cd ~/regexp-practice            # каталог с t01.txt … t14.txt
grep -E '\bcat\b' t01.txt
grep -oE '[0-9]' t02.txt
grep -oE '\b[a-z]{3}\b' t03.txt
grep -oE '[0-9]+' t04.txt
grep -oE '\b[A-Z][a-z]*\b' t05.txt
grep -oE '[[:alnum:]._%+-]+@[[:alnum:].-]+\.com' t06.txt
grep -E '^(0[1-9]|[12][0-9]|3[01])\.(0[1-9]|1[0-2])\.(19|20)[0-9]{2}$' t07.txt
grep -oP '\b\w*([a-z])\1\w*\b' t08.txt
grep -oP '<([a-z]+)>.*?</\1>' t09.txt
grep -P '^(?=.*[0-9])(?=.*[a-z])(?=.*[A-Z])(?=.*[!@#$%^&*]).{8,}$' t10.txt
grep -oE 'https?://[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}' t11.txt
grep -P '^([0-9]{1,3}(,[0-9]{3})+|[0-9]+)$' t12.txt
grep -oiP '\b(\w+)\s+\1\b' t13.txt
grep -oP '"[^"\\]*(?:\\.[^"\\]*)*"' t14.txt | sed 's/^"//;s/"$//'
```
